Giza PAT Platform — CSS V2
==========================
المرحلة الثانية من إعادة تصميم المنصة.

الملف الرئيسي للتصميم:
assets/css/style.css

تم في هذه المرحلة:
- تطوير الهوية البصرية بألوان أزرق أكاديمي + سماوي + ذهبي.
- إعادة تصميم الهيدر والشعار والرؤية والرسالة.
- تطوير Hero الرئيسي وبطاقات الخدمات والأنظمة.
- تحسين النماذج والأزرار والبطاقات والإحصائيات.
- إعادة تصميم Footer.
- تحسين الاستجابة للموبايل والتابلت والشاشات الكبيرة.
- الإبقاء على منطق Python وStreamlit والبيانات كما هي.

لتعديل الألوان الأساسية لاحقاً، ابحث في style.css عن :root.
